# Vendor Security Review and Onboarding Policy (v2.2)

## 1. Scope
Every new software or infrastructure vendor that will store, process or transmit company data must pass a security review before the first purchase order is released. Renewals are re-reviewed every 24 months or when the vendor's service scope changes materially.

## 2. Review steps
2.1 The requesting team submits a business justification and a data classification for the information the vendor will handle.
2.2 Security sends the vendor a standard questionnaire covering access control, encryption in transit and at rest, logging, sub-processors and breach notification.
2.3 Security reviews independent attestations such as SOC 2 Type II or ISO 27001 and records any exceptions.
2.4 Legal reviews data protection terms. Procurement confirms insurance certificates.

## 3. Risk tiers
- Tier A: handles restricted data (customer personal data, credentials). Requires penetration test evidence and an annual review.
- Tier B: handles internal data. Requires the questionnaire and attestations.
- Tier C: no company data. Requires only a basic vendor profile.

## 4. Approval
Tier A needs sign-off from the Chief Information Security Officer. Tier B needs the Security Manager. Tier C needs the budget owner.

## 5. Offboarding
When a contract ends, the owner must confirm that data has been returned or deleted, access has been revoked and any keys have been rotated. Evidence is kept for audit.
