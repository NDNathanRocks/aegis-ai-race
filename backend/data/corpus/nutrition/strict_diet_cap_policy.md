# Strict Diet Cap Policy (order audit rules)

## 1. Purpose
This policy defines how a custom sandwich order is audited against a strict diet cap. The rules are mechanical so that the same order always produces the same result.

## 2. The four caps
- Calories: the order total must be strictly below the calorie cap (for example, a cap of fewer than 950 kcal). A total equal to the cap fails.
- Protein: the order total must be strictly above the protein floor (for example, more than 55 g).
- Sodium: the order total must be strictly below the sodium cap (for example, fewer than 1,800 mg).
- Dairy: the order must contain ZERO dairy. Any ingredient whose allergen list includes milk fails the dairy rule, including cheese, bread that contains cheese, and sauces that contain milk, buttermilk, whey or casein.

## 3. How to total an order
Add the kcal, protein and sodium columns of the footlong matrix for every selected ingredient. A "double" portion counts the ingredient twice. Use footlong values for a footlong order; six-inch values must never be used for a footlong.

## 4. Reporting violations
List every rule that fails, with the order total and the amount by which the cap is missed. For the dairy rule, list every ingredient that contains milk. Do not stop at the most obvious one: cheese is obvious, but bread and sauces can also contain milk.

## 5. Passing rules
Say which rules pass as well. A rule that passes must be reported as passing with its total, not omitted and not reported as violated.

## 6. Allergen non-dairy items
Soy, egg, wheat and fish allergens are not dairy. They do not fail the dairy rule, but they must be listed when the customer asks for allergen information.
